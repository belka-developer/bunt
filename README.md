# Бунт

**Бунт** собирает сетевые инструменты в одном окне Windows: обход блокировок Discord, YouTube и Telegram, VPN (FPTN, WireGuard, AmneziaWG, VLESS) и быстрая смена DNS. Ничего не нужно настраивать руками в консоли и батниках: нажали «Установить», затем переключатель.

Бунт ничего не устанавливает в систему втихую. Всё скачанное лежит в папке `modules` рядом с программой, а при отключении Бунт возвращает сеть в исходное состояние.

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/home.png" alt="Главная страница Бунта" width="760"></p>

## Что внутри

| Раздел | Для чего | Основа |
|---|---|---|
| **Zapret (Discord)** | Открывает Discord и YouTube, подбирает рабочую стратегию | [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) |
| **Zapret (Telegram)** | Локальный прокси для Telegram Desktop | [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) |
| **VLESS** | Свои серверы и подписки, весь трафик или только нужные приложения и сайты | [Xray-core](https://github.com/XTLS/Xray-core) |
| **WireGuard** | Профили WireGuard и AmneziaWG из файлов `.conf` | [AmneziaWG](https://github.com/amnezia-vpn/amneziawg-windows-client) |
| **FPTN** | VPN по токену доступа | [FPTN](https://github.com/fptn-project/fptn) |
| **DNS** | Смена DNS одним нажатием: Cloudflare, Google, Яндекс и другие | встроенный |
| **Безопасность** | Проверка, что файлы компонентов не подменены | встроенный |

## Установка

1. Откройте страницу [Releases](https://github.com/belka-developer/bunt/releases/latest) и скачайте файл `Bunt_…_x64-setup.exe`.
2. Запустите его. Если Windows пишет «Система Windows защитила ваш компьютер», нажмите **Подробнее**, затем **Выполнить в любом случае**: у программы пока нет платной подписи кода (SmartScreen пугает все новые программы).
3. Установщик ставит Бунт для всех пользователей, поэтому Windows спросит разрешение (UAC). Согласитесь.
4. Запустите Бунт. Для VPN, DNS и запретов нужны права администратора: если их нет, вверху окна появится кнопка **«Дать права»**. Нажмите её, Бунт перезапустится от имени администратора.

Обновляется Бунт сам: на вкладке **«Обновления»** нажмите «Проверить», а если есть новая версия, «Обновить». Без вашего нажатия ничего не скачивается.

## Как пользоваться

Во всех разделах всё одинаково: слева выбираете раздел, сверху справа переключатель включает и выключает функцию. Если компонент ещё не скачан, вместо переключателя будет кнопка **«Установить»**. Бунт скачает файлы с GitHub, проверит их хеш и распакует в `modules`.

### Discord и YouTube

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/discord.png" alt="Раздел Zapret для Discord и YouTube" width="760"></p>

1. Откройте **Zapret (Discord)** и нажмите «Установить».
2. Нажмите **«Подобрать стратегию»**: Бунт по очереди запускает варианты, проверяет, открываются ли Discord и YouTube, и выбирает тот, при котором открывается всё. **«Проверить стратегии»** проверяет все варианты и ничего не переключает. Если навести курсор на оценку вроде 5/6, видно, какие сервисы открываются. Выбрать стратегию вручную можно, нажав на карточку. Проверка не работает при включённом VPN.

В том же разделе есть остальное из `service.bat` Flowseal: **Game Filter** с режимами TCP, UDP и своими портами, редактор своих списков и обновление списка IP, замена фейков, добавление записей в `hosts` (с показом всех строк до записи), диагностика с очисткой кэша Discord, свои сайты для проверки и установка запрета **службой Windows**, которая работает без Бунта.
3. Включите переключатель вверху справа.

Если Discord или YouTube перестали открываться, нажмите «Подобрать стратегию» ещё раз: провайдеры меняют блокировки. **Game Filter** добавляет обход для игр, **IPSet Filter** меняет охват списков (режим `any` затрагивает все сайты, включайте его только для проверки). При удалении раздела Бунт полностью останавливает запрет, службу и драйвер.

### Telegram

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/telegram.png" alt="Раздел Zapret для Telegram" width="760"></p>

1. Откройте **Zapret (Telegram)** и нажмите «Установить» (Бунт сам ставит всё нужное для прокси, это занимает около минуты).
2. Включите переключатель.
3. Нажмите **«Копировать»** рядом со ссылкой `tg://proxy…` и откройте её в Telegram Desktop или вставьте в браузер: Telegram предложит подключить прокси. Подтвердите.

Порт и секрет можно оставить как есть. Чтобы прокси работал всегда, включите «Запускать вместе с Windows».

### VLESS

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/vless.png" alt="Раздел VLESS" width="760"></p>

1. Откройте **VLESS**, нажмите «Установить».
2. Вставьте ссылку `vless://…` (можно несколько, по одной в строке) или адрес подписки `https://…` в поле под списком и нажмите «Добавить». Подписку потом можно обновлять кнопкой.
3. Выберите сервер в списке (кнопка «Проверить пинг» покажет, какой отвечает быстрее) и включите переключатель.

**Режим** справа:
- **TUN**: через сервер идёт весь трафик компьютера, подходит для игр и любых программ. Нужны права администратора.
- **Прокси**: включается системный прокси Windows. Работает без администратора, но программы, которые игнорируют системный прокси, пойдут мимо.

**Правила** позволяют решать, что идёт через VLESS, что напрямую, а что блокируется: отдельно для приложений (например, `Discord.exe`; удобнее выбрать из запущенных), для доменов (`example.com` с поддоменами, `geosite:google`) и для сетей (`geoip:ru`). Правила проверяются сверху вниз, а всё остальное идёт по пункту «По умолчанию». Кнопка **«Российские сайты напрямую»** добавляет готовый набор. Правила применяются при следующем подключении.

### WireGuard и AmneziaWG

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/wireguard.png" alt="Раздел WireGuard и AmneziaWG" width="760"></p>

1. Откройте **WireGuard**, нажмите «Установить».
2. Перетащите файл `.conf` в рамку (или нажмите на неё, или «Вставить текст»). Обычные конфиги и конфиги AmneziaWG с обфускацией определяются сами.
3. Выберите профиль и включите переключатель.

Профили со сценариями `PostUp` и `PreDown` Бунт не принимает: такие сценарии выполняются от имени системы. Ключи хранятся в `modules\wg\data` и доступны только администраторам.

### FPTN

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/fptn.png" alt="Раздел FPTN" width="760"></p>

1. Откройте **FPTN**, нажмите «Установить».
2. Вставьте токен доступа (`fptn:…` или `fptnb:…`) и нажмите «Сохранить». Бунт покажет список серверов.
3. Выберите сервер (или оставьте «Автовыбор») и включите переключатель.

Токен это ваш пароль: никому его не показывайте и не выкладывайте. Если токен попал в чужие руки, перевыпустите его у поставщика.

### DNS

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/dns.png" alt="Раздел DNS" width="760"></p>

Выберите карточку с нужным сервером, и Бунт сразу применит его к отмеченным адаптерам. Тумблер вверху справа включает и выключает DNS: выключенный DNS снова выдаёт роутер или провайдер, а при включении возвращается ваш последний выбор. «Проверить скорость» покажет, какой DNS отвечает у вас быстрее всех. Прежние настройки Бунт запоминает: кнопка **«Вернуть»** возвращает всё как было, **«Автоматически»** отдаёт DNS роутеру. Пока включён любой VPN, DNS не меняется: VPN управляет им сам.

### Безопасность, обновления, настройки

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/security.png" alt="Проверка целостности" width="760"></p>

**«Безопасность»**: быстрая проверка сверяет файлы компонентов с хешами, записанными при установке, а «Сверить с GitHub» сравнивает с оригинальным релизом. Если что-то отличается, Бунт предложит переустановить компонент.

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/updates.png" alt="Обновления" width="760"></p>

**«Обновления»**: версии Бунта и всех компонентов. Для каждого компонента можно «Переустановить» или «Удалить».

<p align="center"><img src="https://raw.githubusercontent.com/belka-developer/media-readme/main/bunt/screens/settings.png" alt="Настройки" width="760"></p>

**«Настройки»**: запуск вместе с Windows, сворачивание в трей, уведомления, автопроверка обновлений. Значок Бунта в трее у часов открывает окно и быстрые переходы по разделам.

## Важно знать

- **Два VPN сразу не включаются.** FPTN, WireGuard и VLESS делят маршруты, и вместе они ломают интернет. Если включить второй, Бунт предложит выключить первый и сам вернёт сеть в исходное состояние.
- **Бунт возвращает сеть сам.** Если программа или компьютер закрылись аварийно, при следующем запуске Бунт сам уберёт следы (маршруты, DNS, системный прокси). Вручную это можно сделать кнопкой **«Починить сеть»** в разделе VPN. Сбрасывать сеть Windows не нужно.
- **Антивирус.** Запрет для Discord использует драйвер WinDivert, и некоторые антивирусы относятся к нему настороженно. Файлы берутся только из официальных релизов проекта и проверяются по хешу. Если антивирус ругается, добавьте папку `modules` в исключения.
- **Что где лежит.** Всё скачанное хранится в `modules` рядом с `Bunt.exe` (обычно `C:\Program Files\Bunt\modules\`). Ваши профили, токены и настройки лежат в папках `data` внутри компонентов и сохраняются при обновлении и переустановке.
- **Удаление.** Сначала удалите ненужные компоненты кнопкой «Удалить» в разделе «Обновления» (Бунт остановит их и уберёт службы и драйверы), затем удалите Бунт через «Приложения» в Windows.

## Что-то не работает

| Проблема | Что делать |
|---|---|
| Не получается включить: «Нужны права администратора» | Нажмите «Дать права» вверху окна |
| Discord или YouTube не открываются | В разделе Zapret нажмите «Подобрать стратегию» ещё раз |
| Компонент не скачивается | Проверьте интернет и повторите: Бунт сам делает три попытки. Если не помогает, отключите VPN и нажмите «Установить» снова |
| Интернет пропал после сбоя VPN | Откройте раздел VPN и нажмите «Починить сеть» |
| VLESS не подключается | В разделе VLESS нажмите «Показать» у журнала: там причина. Проверьте ссылку и режим |
| Правило для приложения не срабатывает | Выберите приложение из списка запущенных: имя процесса чувствительно к регистру |

Не нашли ответ? Откройте [Issue](https://github.com/belka-developer/bunt/issues) и приложите текст из журнала раздела (токены и ключи в журналах не пишутся, но лишнее перед отправкой всё равно проверьте).

# Для разработчиков: форк и самостоятельная сборка

Дальше только для тех, кто хочет собрать Бунт сам или сделать свой форк.

Приложение написано на Tauri 2: бэкенд на Rust, интерфейс из обычных HTML, CSS и JS без сборки.

## Запуск для разработки

Нужны Windows 10 или 11, [Rust](https://rustup.rs) (stable), Node.js 20+ и WebView2 (в Windows 11 он уже есть).

```
npm install
npm run dev
```

Интерфейс лежит в `ui/` и ничем не собирается. Правки в `index.html`, `styles.css` и `app.js` видны после перезапуска окна. Файл `ui/index.html` можно открыть и в обычном браузере: так виден макет без Rust (с примерными данными). Если добавить к адресу `?app`, окно выглядит как в приложении.

Тесты бэкенда (часть из них работает и на Linux и macOS, Windows-код при этом не собирается):

```
cd src-tauri
cargo test
```

## Структура

```
src-tauri/src/   бэкенд на Rust
  lib.rs         окно, трей, регистрация команд
  modules.rs     скачивание, проверка и установка компонентов
  zapret.rs      запрет Discord и YouTube (winws, служба, WinDivert)
  telegram.rs    прокси для Telegram
  fptn.rs        FPTN и защита сети
  wg.rs          WireGuard и AmneziaWG
  vless.rs       VLESS на Xray-core
  dns.rs         смена DNS
  vcredist.rs    окно C++ Redistributable при установке FPTN
  integrity.rs   проверка целостности
  settings.rs    настройки Бунта, права администратора
ui/              интерфейс: index.html, styles.css, app.js, fonts/
scripts/         bump.mjs: подъём версии
.github/         workflows: выпуск релиза и сборка для проверки
CHANGELOG.md     описание версий (попадает в релиз)
```

## Быстро получить свою сборку

Сделайте форк, откройте у него вкладку Actions, выберите слева «Сборка для проверки» и нажмите Run workflow. Минут через десять внизу страницы запуска, в разделе Artifacts, появится `Bunt-setup` с установщиком. Ключи для этого не нужны, но такая сборка не умеет обновляться.

## Свой форк с обновлениями

1. Замените адреса репозитория:
   - `src-tauri/tauri.conf.json`: `plugins.updater.endpoints` (ссылка на `latest.json` вашего репозитория) и `publisher`;
   - `src-tauri/src/modules.rs`: функция `source` (пара «владелец, репозиторий» для `app`) и, если нужно, источники компонентов;
   - `src-tauri/src/settings.rs`: список разрешённых адресов в `open_url`;
   - `ui/index.html` и `ui/app.js`: ссылки на GitHub в разделе «Настройки» и на главной.
2. Создайте свою пару ключей для подписи обновлений и подключите её, как описано ниже. Чужие ключи использовать нельзя.
3. Репозиторий и релизы должны быть публичными, иначе приложение не скачает `latest.json`.

## Обновления из GitHub: как это устроено

### Как это работает

1. Пользователь нажимает «Проверить» на главной или «Проверить обновления» в меню трея. При запуске приложение тоже тихо проверяет обновления, и об этом сообщает, только если версия новее.
2. Приложение скачивает небольшой файл `latest.json` по адресу `https://github.com/belka-developer/bunt/releases/latest/download/latest.json`.
3. Если там версия новее установленной, в сводке появляется кнопка «Обновить». Ничего не скачивается, пока её не нажали.
4. По нажатию приложение скачивает установщик, проверяет его подпись по публичному ключу, зашитому в приложение, запускает установщик и перезапускается. Если подпись не совпала, ничего не ставится.

Установщик ставит Бунт для всех пользователей в Program Files, поэтому при обновлении Windows показывает запрос UAC.

### Настройка (один раз)

1. Создайте пару ключей для подписи обновлений. Команда спросит пароль:

   ```
   npx tauri signer generate -w "$HOME/.tauri/bunt.key"
   ```

   В PowerShell путь пишется так: `$HOME\.tauri\bunt.key`. Рядом появится файл `bunt.key.pub`.

2. Вставьте содержимое `bunt.key.pub` в `src-tauri/tauri.conf.json`, поле `plugins.updater.pubkey` (вместо `REPLACE_WITH_PUBLIC_KEY`).

3. В репозитории на GitHub откройте Settings, Secrets and variables, Actions и добавьте два секрета:
   - `TAURI_SIGNING_PRIVATE_KEY`: содержимое файла `bunt.key`;
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: пароль от ключа.

> Приватный ключ нельзя коммитить, и его нельзя терять. Без него вы не сможете подписать новую версию, и всем пользователям придётся переустанавливать Бунт вручную.

Репозиторий и релизы должны быть публичными, иначе приложение не скачает `latest.json`.

### Быстро получить exe без ключей

Откройте на GitHub вкладку Actions, выберите слева «Сборка для проверки» и нажмите Run workflow. Минут через десять внизу страницы запуска, в разделе Artifacts, появится `Bunt-setup` с установщиком. Ключи для этого не нужны, но обновляться такая сборка не сможет: она без подписи.

### Выпуск новой версии

```
npm run bump -- 0.1.1
git commit -am "v0.1.1"
git tag v0.1.1
git push && git push --tags
```

`bump` меняет версию сразу в `tauri.conf.json`, `Cargo.toml` и `package.json`. Тег запускает workflow `.github/workflows/release.yml`: он собирает установщик, подписывает его и публикует релиз вместе с `latest.json`. Если версия в `tauri.conf.json` не совпадает с тегом, сборка остановится.

Текст релиза на GitHub показывается пользователю как описание обновления, поэтому пишите его по-человечески.

### Как проверить всю цепочку

1. Выпустите `v0.1.0` и установите Бунт из релиза.
2. Выпустите `v0.1.1`.
3. В запущенном 0.1.0 нажмите «Проверить», затем «Обновить».

Локальная сборка установщика (`npm run build`) требует переменной окружения `TAURI_SIGNING_PRIVATE_KEY` (путь к ключу или его содержимое), потому что включены файлы для обновлений. Для разработки хватает `npm run dev`.

Установщик пока не подписан сертификатом кода, поэтому Windows SmartScreen может показать предупреждение.

## Компоненты и права администратора

Всё скачанное лежит в папке `modules` рядом с `Bunt.exe` (обычно `C:\Program Files\Bunt\modules\`): `modules\<компонент>\<версия>\`, активная версия записана в `modules\state.json`, временные файлы в `modules\.staging\`. Новая версия ставится рядом со старой.

Запись в Program Files, запуск `winws` и драйвер WinDivert требуют прав администратора. Бунт стартует без них (иначе Windows не пускает его в автозапуск), а если прав нет, показывает кнопку «Дать права»: она перезапускает Бунт от имени администратора. Автозапуск это запись в разделе Run реестра, она видна в «Автозагрузке» диспетчера задач. Для `npm run dev` с запретом откройте терминал от имени администратора.

## Как устроены компоненты внутри

- **Zapret (Discord):** Бунт скачивает релиз Flowseal, распаковывает в `modules\discord\<версия>` и запускает `winws.exe` скрыто. При удалении останавливает процесс, службу `zapret` из своей папки и драйверы WinDivert.
- **Telegram:** исходники `tg-ws-proxy` плюс встроенный Python (`runtime`), прокси запускается без окна, настройки и лог лежат в `modules\telegram\data`.
- **FPTN:** официальный установщик из релиза `fptn-project/fptn` ставится тихо в `modules\fptn\<версия>`, клиент запускается без окна. Перед подключением запоминаются шлюз физического адаптера и статические DNS, после отключения или сбоя Бунт убирает маршруты FPTN, возвращает DNS и при желании удаляет адаптер Wintun. Окно установки C++ Redistributable Бунт перехватывает и ставит его тихо, если он нужен.
- **WireGuard и AmneziaWG:** MSI клиента не ставится в систему, `msiexec /a` только распаковывает его в `modules\wg\<версия>`. Туннель это служба Windows (`amneziawg.exe /installtunnelservice`) с ручным запуском, поэтому после перезагрузки VPN сам не поднимется. По умолчанию `0.0.0.0/0` заменяется на `0.0.0.0/1` и `128.0.0.0/1`: клиент не включает брандмауэр-«выключатель», и Radmin VPN, Hamachi и локальная сеть продолжают работать.
- **VLESS:** ядро Xray-core в `modules\vless\<версия>` и подписанный wintun.dll (подпись проверяется). Бунт сам собирает конфиг из профиля и правил (`process`, `domain`, `ip`), проверяет его командой `xray run -test` и запускает ядро скрыто. Адрес сервера заранее превращается в IP, чтобы ядру не нужен был DNS для подключения. Профили с ключами лежат в `modules\vless\data` и закрыты для обычных пользователей.
- **DNS:** `Set-DnsClientServerAddress` для выбранных физических адаптеров, прежние настройки сохраняются в `modules\dns.json`. Для DoH (Windows 11) регистрируются адреса шифрованных серверов.
- **Защита от двух VPN:** FPTN, WireGuard и VLESS проверяют друг друга в `connect_blocking`, интерфейс показывает окно выбора.

## Как добавить новый компонент

1. Добавьте его в `source` в `modules.rs` (откуда качать) и напишите установку по образцу `install_wg` или `install_vless`: скачать, проверить хеш, распаковать в `modules\<id>\<версия>`.
2. Заведите модуль с командами (`wg.rs` самый компактный образец), зарегистрируйте их в `lib.rs`, а при выходе и удалении вызывайте остановку (`shutdown`, `stop_all`).
3. Если компонент меняет сеть, запоминайте состояние перед подключением и возвращайте после (`fptn::probe`, `fptn::repair_script`), а в `connect_blocking` проверяйте, что другой VPN не включён.
4. Добавьте страницу в `ui/index.html`, логику в `ui/app.js` и запись в `integrity.rs`.
5. Опишите изменение в `CHANGELOG.md`: текст раздела попадает в описание релиза и в окно «Что нового».
